Every coding agent and every account, in one native Linux app

Run several Claude Code and Codex accounts side by side, next to Antigravity, Muse and Oh My Pi, each agent with its own terminals, diffs and pull requests.

Install for Linux Source on GitHub

Linux x86_64 on Wayland · MIT licensed · In beta

Features

Every account, side by side

Add each Claude Code and Codex login you have. Every account keeps its own sign-in and shows how much of its allowance is left, and you choose one per conversation, so a personal and a work account can run at the same time.

Set a provider to Automatic and new conversations start on a signed-in plan, moving to another when its allowance runs out.

All your agents in one window

Conversations from every provider sit together, grouped by project and worktree, in one native interface rather than a separate terminal or app for each.

Switch a Claude Code or Codex session between a real terminal and a native chat of the same conversation. Commands, edits and tool calls stay one line each until you open them.

Around the agents

  • A worktree per task

    Create a worktree from a branch name or a Linear issue. The sidebar shows which agents are working, waiting for you, or have output you haven't read.

  • Review in place

    Read the diff, stage and commit, browse history and review pull requests, with GitHub's viewed marks kept in sync.

  • An editor beside the chat

    Syntax highlighting, autosave and optional language servers. It also ships on its own as ceditor.

  • Sessions outlive the window

    A per-user daemon owns every terminal and conversation. Restart the app and your agents keep going; compatible updates keep the daemon and your sessions running.

  • Other machines, same workspace

    Connect to another computer's daemon over SSH for its terminals, chats, files, Git and worktrees. Device windows

  • Keyboard first

    Chats, terminals, editors and browsers sit in one horizontal strip. Move with Ctrl+PgUp and Ctrl+PgDn, and resize the focused pane with Alt+R.

  • Scriptable from the shell

    Start agents, send prompts and read structured results without a window, or let sessions message each other. Agent execution 

    $ cagents agent spawn --provider claude --wait \
    "Find out why the e2e suite is flaky"
$ cagents --json sessions

Install

Run this in a system terminal. It looks up the latest release, checks the installer and the archive against the release's SHA-256 manifest, and installs cagents for your user without root or a GitHub account.

A copy installed this way updates itself: cagents checks for signed releases and offers each one in the app. Compatible updates keep the daemon and your sessions running.

Prefer a package? Download the Debian package, with or without the embedded browser, or a portable archive from the latest release.

Needs Linux x86_64 with Wayland, glibc 2.35 and Git 2.36 or newer. Bring the agent CLIs you use, signed in with your own accounts. Installation guide
