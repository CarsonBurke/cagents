A native workspace for coding agents

Run Claude Code and Codex from multiple accounts alongside Antigravity, Muse and Oh My Pi. Give each task its own Git worktree and review the changes beside the conversation.

Features

Use work and personal accounts side by side

See the remaining allowance for each Claude Code and Codex account and pick one when you start a conversation.

Choose Automatic to let cagents pick an account and switch to another signed-in plan when the current one runs out.

Chat and terminal for the same session

Switch between a terminal and native chat in a Claude Code or Codex session. In chat, expand a command, edit or tool call to see its details.

From worktree to pull request

  • A worktree per task

    Start from a branch name or Linear issue. Check the sidebar for agents at work, waiting for input, or with unread output.

  • Review changes beside the conversation

    Read diffs, stage files and commit. When you review a pull request, files you mark as viewed stay in sync with GitHub.

  • An editor beside the chat

    Open and edit the files your agent is working on. The editor has syntax highlighting, autosave and optional language servers.

  • Sessions outlive the window

    Close the window or restart the interface while your agents and terminals keep running in the background.

  • Work on another machine over SSH

    Open a remote machine's chats, terminals, files and Git worktrees from your local window. Device windows

  • Move between panes by keyboard

    Press Alt+Q or Alt+R to move between panes, or ⌘+⌥+Left and ⌘+⌥+Right on a Mac. Resize the focused pane without leaving the keyboard.

  • Run agents from a script

    Send prompts and read structured results from the CLI, with the app window closed. Agent execution 

    $ cagents agent spawn --provider claude --wait \
    "Find out why the e2e suite is flaky"
$ cagents --json sessions
